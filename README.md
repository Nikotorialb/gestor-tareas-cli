# Gestor de Tareas CLI

## Descripción
Aplicación de consola desarrollada en Python
para administrar tareas de manera sencilla.

## Requisitos previos
- Python 3 instalado.
- Git instalado.

## Funcionalidades
- Agregar tareas.
- Listar tareas.
- Completar tareas.
- Eliminar tareas.

## Instrucciones de uso
Ejecutar el siguiente comando:

python app.py
